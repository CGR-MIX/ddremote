# DD远程

DD远程是面向Windows和Android的远程桌面预览版。Windows电脑可以共享桌面，也可以控制另一台电脑；Android用于连接电脑、传文件和交换文字。串流基于Sunshine / Moonlight，账户网络内嵌Tailscale。

**接手 UI 开发请先读 [UI 开发交接](docs/UI-HANDOFF.zh-CN.md)。** 当前 Windows 源码版本为 `0.3.3-super-screen-lab`；Android 同时保留可独立从源码构建的 `apps/android` 和 `0.3.4` 本地 UU 适配实验。交接文档说明修改入口、启动方式、接口约定及验收要求。

**以下使用说明主要记录 Windows 0.2.0-preview、Android 0.2.1-preview 的基线，尚未完整对齐UU远程。** 已实现账户设备入口、共享开关、自动首次配对和文件/文字通道。Android 0.2.1修复登录时网络组件初始化错误，已在Android 16模拟器复现旧版错误并验证新版能打开授权页面。真实账户登录完成、云端设备删除、不同网络的双机连接以及Android真机画面、声音和输入，仍需要独立验收。

## 交付文件与运行条件

- Windows：`dist/DDRemote-Windows-x64.exe`，需要x64 Windows、Microsoft Edge WebView2 Runtime，以及可用的显示与编码环境。
- Android：`dist/DDRemote-0.2.1-preview-android.apk`，最低Android 5.0 / API 21，包含arm64-v8a、armeabi-v7a、x86和x86_64四种ABI及内嵌账户网络。同签名、版本码3，可覆盖安装0.2.0。
- 文件校验：交付目录中的SHA-256清单用于核对下载或复制后的文件。

两端需使用同一个Tailscale账户，能打开系统浏览器完成登录；账户管理员要求的设备批准仍需完成。DD已内嵌网络，不要求另装Tailscale客户端。DD使用Tailscale账户身份，不提供独立的DD云账号；同一网络中的不同账户不等于同一账号授权。

## 开始使用

1. 在被控电脑打开Windows EXE，进入“我的设备”，点击“登录账户”，在系统浏览器完成登录。
2. 回到DD，在“这台电脑”点击“开始接收”，等待状态变为可接收连接。登录本身不会开启桌面或文件共享。
3. 在另一台Windows电脑或Android手机打开DD，登录同一个账户。设备页会自动发现实际运行DD的电脑；首次发现需要等待片刻。
4. 在准备好的电脑条目上点击“远程控制”（手机显示“点击连接桌面”）。程序自动完成首次配对，不需要手动输入IP或PIN。连接失败时按页面或控制窗口中的实际错误处理。
5. 结束使用时关闭远程桌面窗口。被控电脑点击“停止接收”即可停止接收连接。

保持被控电脑上的DD运行。当前Windows版使用便携会话，不是开机登录前即可工作的系统服务。显示器、编码器、声音、输入权限以及目标电脑状态都会影响连接结果。

## 退出和设备移除

“退出并移除此设备”会注销当前账户节点，并停止该会话使用的连接。彻底关闭DD后，也需在下次打开时重新登录；不保留自动恢复登录的选项。最小化窗口或手机普通切到后台不会主动注销。

联网正常时，退出会请求从Tailscale设备列表移除本设备。断网或服务不可达时，程序仍会断开，并说明尚未确认立即移除；异常崩溃、系统杀进程或Android强制停止可能无法执行退出回调，服务端随后回收离线节点。不要把本地列表消失当作服务端已立即删除的证明。

退出还会撤销本机桌面配对和旧文件链接，并清理控制端会话凭据。重新打开DD同样使用新的会话授权；接收的文件保存在本机目录中，退出账户不会删除这些文件。清理失败会显示具体错误，无法确认桌面授权已清理时禁止重新开启接收。具体行为见[功能与授权边界](docs/feature-parity.md)。

## 文件与剪贴板

手机的账户设备条目提供“文件与剪贴板”入口，可访问已经开始接收的电脑。Windows“文件与剪贴板”页可查看接收目录、生成手动连接链接，以及按按钮读取或写入本机文字剪贴板。

- 文件仅来自Windows的“接收文件”目录。也可用“打开文件夹”放入希望手机下载的普通文件。
- 单文件上限1 GiB；暂不支持文件夹、批量拖拽、断点续传或传输百分比。
- 剪贴板仅支持按按钮交换文字，上限约1 MiB；不提供自动监听、图片或文件剪贴板。
- 手动连接链接含授权凭据，只应交给信任的设备。撤销文件链接不会替代桌面配对撤销。

## 高级连接与故障处理

主流程使用账户设备列表。“高级连接”保留兼容Sunshine的手动地址、PIN配对和网络诊断；本机DD桌面的手动连接应使用页面显示的账户地址。文件页中的局域网地址只用于相应文件服务，不代表本机DD桌面支持局域网地址直连。

| 现象 | 检查方式 |
| --- | --- |
| 界面无法创建 | 安装或修复WebView2 Runtime后重开DD |
| 设备没有出现 | 确认两端账户相同、目标DD正在运行、网络已登录；若提示等待设备授权，先完成批准 |
| 电脑出现但不可连接 | 在被控电脑开始接收，等待显示与编码器准备完成；查看该设备的错误说明 |
| 开始接收失败 | 在“设置与帮助”查看运行日志；已有串流组件或端口冲突需先确认来源，DD不会替你终止其他软件 |
| 控制窗口打开后报错 | 以控制窗口的错误为准；打开窗口只表示启动了控制端 |
| 找不到文件 | 确认电脑已开始接收、文件位于接收目录，随后刷新列表 |

“设置与帮助”中的串流管理页用于调整显示器、编码器等选项；“开源许可”可查看组件声明。不要仅凭画质菜单选项判断已经达到4K、144fps、HDR或4:4:4。

## 当前范围与验证

多路并发屏幕、虚拟显示器管理、防窥黑屏、无线副屏、自动解锁、远程会话结束自动锁屏和完整跨网唤醒辅助节点尚未对齐UU远程。

本机真实测试已覆盖Sunshine与portable Moonlight经生产TCP/UDP代理的自动首次配对、证书保存及后续双向TLS身份验证。另一次720p/30fps串流测试记录了约12秒真实帧，接收约30.38fps、渲染约30.11fps，并收到音频首包。这是同机局部链路结果，不代表真实Tailscale账户、异地网络、Android真机或更高画质已经通过测试。

两个本机真实tsnet节点另已通过同账号WireGuard身份校验、双向设备发现及注销后的本地清理。使用的是上游测试控制面；它不实现临时节点注销删除，因此仍不能代替真实云端删除验收。

构建、签名、校验值及实测范围见[验证记录](docs/validation/release-0.2.0.md)，完整逐项状态见[功能对齐与验收边界](docs/feature-parity.md)。Windows EXE未使用商业代码签名证书；APK已使用本项目本地发布密钥签名。

Android登录修复及模拟器对照测试见[0.2.1验证记录](docs/validation/android-0.2.1.md)。
