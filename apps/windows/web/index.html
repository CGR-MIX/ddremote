向同一局域网中的电脑发送 Wake-on-LAN 唤醒请求。

目标电脑的主板与网卡需启用网络唤醒并保持供电。发送成功只代表请求已发出，不能确认电脑已开机。跨网唤醒需要目标局域网内的在线辅助设备。

开始使用

Windows 与 Android

远程桌面

Windows 电脑登录同一 Tailscale 账户后，会在“我的设备”显示实际可发现的 DD设备。被控电脑需手动点击“开始接收”，控制端点击“远程控制”即可发起自动配对与连接。手机也需完成同一 Tailscale 账户登录。需要手动连接时，可使用“高级连接”里的账户地址与 PIN 配对。

文件与文字

打开“文件与剪贴板”，选择手机能访问的地址并生成二维码。手机粘贴连接链接后，即可发送文件或交换文字。桌面配对和文件传输链接分别授权。

功能与验证范围

可用能力以此设备返回的状态和实际连接结果为准。菜单中的画质选项不代表已达到对应性能。多屏并发、虚拟显示器、防窥黑屏、自动解锁及无人值守开机不能仅由基本串流保证，需对应组件与验证。遇到失败时，请先查看下面的运行日志。
