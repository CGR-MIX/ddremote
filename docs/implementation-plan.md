1. 从真实源码构建 Windows EXE 和 Android APK，记录版本、构建命令和 SHA256。

## 界面设计

颜色：纸白 #F8FAFD、深蓝 #152C56、连接蓝 #245FE5、青绿 #168B7D、浅蓝灰 #E8EEF8、警示橙 #B56A16。

字体：Windows 优先 Microsoft YaHei UI / Segoe UI，Android 系统中文字体。设备名称与连接状态是首要信息，地址保持易复制，设置与高级诊断渐进展示。

布局：左侧简短导航，右侧以“这台电脑”作为连接主体；配对区与网络区连贯排列，文件面板使用实际文件列表。避免假设备、假速率与虚构在线状态。

交互：提供清晰的开始/停止控制、登录网络、配对、复制地址、传输进度、错误修复入口。每项敏感操作由可见按钮触发。
