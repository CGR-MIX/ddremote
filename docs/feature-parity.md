# DD远程 0.2.0-preview 功能对齐与验收边界

记录日期：2026-11-20（Asia/Hong_Kong）。对照对象为用户提供的 UU远程 Windows 4.48.1.5606 安装包及当日官网功能说明。完整基线、静态证据和官方快照见 `research/uu/README.md`。

**当前是基于 Sunshine、Moonlight 与 Tailscale 的预览版，尚未实现 UU远程全部功能。** 本表以实际源码为依据，区分“已有实现”“依赖外部组件”“未实现”“未完成验证”。EXE/APK 构建成功、菜单出现或进程启动成功，都不能单独证明远程桌面已经连接、达到标称帧率或完成跨网验证。

## 交付平台与构成

- Windows：Go 编写的 DD控制台，内嵌 WebView2 中文界面；启动内置 Sunshine 主机，调用内置 Moonlight 桌面控制端，使用 `tailscale.com/tsnet` 作为本进程独立的安全网络节点。
- Android：基于 Moonlight Android 的 DD启动入口，保留真实 GameStream 配对/串流栈，新增 HTTPS 文件与文字剪贴板客户端。
- Android已内嵌tsnet账户网络，0.2.0-preview APK包含arm64-v8a、armeabi-v7a、x86、x86_64四种ABI的`libddnetwork.so`，无需另装Tailscale。最低Android API 21；账户发现、自动配对、串流和文件入口已接入，真实设备与账户端到端验证尚未完成。
- 账户默认随当前程序会话使用：退出账号会移除此设备；彻底关闭DD后注销，重开需重新登录。最小化与手机进入后台不主动注销，不提供额外“临时模式”开关。
- Windows 使用当前用户的便携会话，关闭 DD控制台将停止其接收服务。没有承诺 Windows 开机前登录、系统级无人值守服务或安全桌面控制。
- 本项目 EXE/APK 不覆盖 UU 的 macOS、iOS、HarmonyOS、Linux 与 TV 全部产品线。

## Windows账户入口与共享边界

“我的设备”以Tailscale账户身份和实际DD设备为主。页面调用`accountDevices`（8秒节流、无并发重入）读取`account/state/devices`；显示账户名称与登录标识。`online=true`、`ready=true`且账户网络处于Running时，才启用“远程控制”；读取失败、离线、未就绪、退出/切换账户或已有连接请求时禁用相应动作。点击只提交设备`id`给`accountConnect`，等待上限100秒，最终展示后端返回信息；打开控制窗口不等于串流已连接。

“登录账户”和“退出并移除此设备”分别调用`accountLogin`、`accountLogout`。登录本身不启动Sunshine或共享文件服务；“开始接收/停止接收”是独立的明确操作。手动IP/PIN、Tailscale网络诊断和通用Moonlight设备库入口收在“高级连接”。高级网络列表是可见网络节点，仅能将地址填入手动连接框，不把在线节点当作可接收的DD设备。主集成任务已验证真实本机自动首配、Qt证书持久化及后续mTLS认证；同账户身份发现与不同网络下的完整流程仍需独立验证，不能用UI桩数据测试代替。

账户生命周期默认采用ephemeral节点与内存状态存储（`mem.Store`），不保存可在重新启动后自动恢复的账户会话。退出通过节点生命周期请求从Tailscale设备列表移除本设备，不只是隐藏DD列表项；仅对普通持久节点执行`Logout`不能替代设备删除。彻底关闭程序同样结束该会话，重开需要重新登录；最小化或Android退到后台不主动注销。正常退出与异常终止时的控制面回收时点、重新登录后设备身份和地址变化，仍需用真实账户验证。

Windows退出会停止自有控制/接收进程、清除Sunshine当前与旧格式的客户端配对记录、旋转文件链接令牌并清除控制端会话目录。重新启动也执行这些授权清理，覆盖上次异常退出。主机UUID、配置和已接收文件保留。目录清理失败时不再复用旧控制端身份；桌面授权清理失败则禁止重新开启接收，并报告错误。

## 文件传输与授权说明

文件通道只共享 `接收文件` 目录中的普通文件。Windows用户可以通过“打开文件夹”放入希望手机下载的文件。文件列表不提供系统磁盘浏览、子目录递归或任意路径下载。

连接链接包含主机地址、随机能力密钥和SHA-256证书指纹；它授权持有者访问共享文件及文字剪贴板。链接不是普通公开网址。Android使用指定证书指纹验证HTTPS，不跟随HTTP重定向；凭据在文件页面内存使用，不写入普通偏好设置。二维码是连接链接的另一种表示；当前Android新增页面没有内置扫码器，以复制/粘贴链接或系统处理 `ddremote://connect` 链接为主。

桌面串流PIN配对与文件能力密钥是两套独立授权。文件页的“撤销旧链接”只处理文件令牌；退出账号同时撤销两类授权。当前没有按设备单独分配“只读文件”“仅剪贴板”“只看屏幕”的权限面板。
