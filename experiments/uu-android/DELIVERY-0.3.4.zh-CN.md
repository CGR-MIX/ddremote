# DD远程 0.3.4 UU 适配试验版

本版安卓以官方 UU 远程 4.48.1 APK 重建，保留原 DEX、资源和原始 InvisibleEditText、StreamerSurfaceView、完整键盘布局。DD 提供账号首页、远控页面和工具栏。连接 Sunshine 仍使用 Moonlight 协议及音频库，没有加载 Moonlight Game 页面。原 UU 的完整 ScreenActivity 和全部界面尚未适配。

## 安装文件

- 手机：DDRemote-UU-0.3.4-mobile-lab.apk，包名 io.ddremote.uuadapter，versionCode 5；可覆盖此前 UU 适配版，与旧 io.ddremote.android 共存。
- 电脑：DDRemote-Windows-0.3.3-super-screen-lab.exe。电脑端沿用已交付的 0.3.3，本次没有重新编译或改版本号。
- 两端使用同一 Tailscale 账号；电脑“开始接收”后，在手机设备列表选择电脑。新包的真实账号发现、跨网连接、退出云端移除仍需小米13真机复测。

## 本次手机优化

- 修复原 UU 输入框在脱离 XML 布局后未声明输入类型的问题；手机中文输入法可以正常请求显示，横屏不会切到全屏文字编辑页。
- 输入法展开时缩小远程画面，收起后恢复；完整键盘面板最多占55%高度，可滚动查看全部按键。
- 触控板和直接触控可切换；支持长按拖动、双指右键/滚动，指针速度0.5—2倍。微小移动和滚动累计后发送，减少低速移动丢失。
- 画质提供720p30/5Mbps、720p60/10Mbps、1080p60/20Mbps；选中后短暂重连。记住画质、触控方式、指针速度和静音偏好。
- 添加静音开关，手机音量键保留本机音量控制；常用复制、粘贴、全选、切换窗口和功能键可从工具栏触发。

## 已验证与实际限制

Android16模拟器：正式签名包安装、冷启动通过，不含测试 instrumentation；v2/v3签名与16KB压缩对齐通过。原UU输入连接的中文/表情、组合键和触控逻辑断言通过。真实Sunshine串流720p95帧、1080p90帧，画质重连、启动取消、释放通过。这些是已显示帧计数，不是实测帧率。

输入法使远程画面高度从1080变496，收起恢复1080；完整键盘保留486像素高的远程画面。一次真实Windows接收测试已收到中文/表情、Ctrl+A替换、左右键、滚轮和拖动。最后版本的Windows接收复测因测试窗口未取得前台而未通过，加入前台校验后的重试未发送输入；不可把这次失败写为通过。

合成音调通过真实Sunshine发送，安卓解码到36个非静音音频回调，静音阶段40个回调通过。最初失败来自测试UDP转发器遇到初期ICMP错误后停止接收，修复测试转发器后通过。小米手机扬声器实际听感尚未验证。

隐私遮罩开启前、开启时、关闭后，远端采样均保持相同测试色块，已验证遮罩不进入Sunshine采集。但没有验证物理显示器实际黑屏，不能把它作为已验收的隐私屏。

超级屏沿用0.3.3：Windows显示布局日志、恢复与租约控制，以及手机开关已实现。当前未安装DD虚拟屏驱动，也未进行虚拟输出/物理输出关闭/恢复的硬件验证。scripts/prepare-super-screen-driver.ps1已完成只读签名核验；安装需要管理员，后续真实测试仍待完成。

原UU完整远控页面、全部高级功能、小米13/Android16真机与真实账号退出删除尚未验收。整体UU功能对齐目标仍未完成。
