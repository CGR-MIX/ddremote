# DD远程 0.3.2 隐私功能试验包

本次包含 Windows EXE 和基于UU原APK重建的Android APK，二者须配套使用。旧0.2.x和0.3.1文件保留。

## 使用

先退出正在运行的旧DD电脑端，再运行 `DDRemote-Windows-0.3.2-privacy-preview.exe`。登录相同账号并开始接收。手机安装 `DDRemote-UU-0.3.2-privacy-lab.apk`，它覆盖同包名的UU适配0.3.1测试版，但不覆盖Moonlight基础的DD0.2.1。

手机远控画面 → DD控制 → 隐私遮罩 → 开启。电脑须解锁。如果手机画面也变黑，关闭隐私遮罩；电脑本地可随时按 **Ctrl+Alt+Shift+F12** 解除，DD电脑页面也提供关闭按钮。

## 本轮已实现

- 手机隐私遮罩开关通过同账号已验证的设备通道请求；电脑把遮罩绑定到该设备和随机会话凭据。
- 手机每4秒续期，电脑15秒租约到期撤销；独立辅助进程另有20秒无续期退出。测试实际观察20.27秒退出，线程调度会有少量延迟。
- 断开/切换画质、退出账号、停止接收、Sunshine退出、DD退出均清理遮罩。父进程崩溃时辅助进程自行退出。
- 本机快捷键解除后，迟到的续期不能重新创建遮罩。锁屏/切换安全桌面或显示布局变化时解除。
- 使用Windows `WDA_EXCLUDEFROMCAPTURE`，只在系统确认设置成功后显示遮罩；这是黑色窗口方案，不是关闭物理屏幕。
- 新增真实显示拓扑读取、快照、只读验证与恢复函数，为超级屏退出恢复提供基础。当前没有调用修改拓扑的功能。

## 验证边界

已通过Windows全部单元测试，含其他设备无法续期/关闭、旧凭据失效、超时、辅助进程退出、真实账号handler到logout清理；旧UI的账号/注销回归通过。

实际辅助进程创建和捕获排除属性确认成功；关闭管道约0.02秒退出，父进程结束约0.26秒退出，无续期约20.27秒退出。真实显示快照在Windows通过 `SDC_VALIDATE`，未应用配置。

**尚未证明“电脑物理屏幕变黑且手机仍见正常桌面”。** 本机真实Sunshine测试没有捕获到四色对照窗口，不能据此判定遮罩有效；直接DDA探测失败，WGC对照采集超时。因此本包只标“试验功能”，不可作为已验证防窥功能使用。

0.3.1已验证的UU画面组件、720p/1080p串流和画质重连代码保留。0.3.2没有完成两台真实设备、真实账号、声音及输入落地复测。
